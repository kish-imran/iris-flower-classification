# 🌸 Iris Flower Classification

## 📌 Project Description

Iris Flower Classification is a Machine Learning project that predicts iris flower species using sepal and petal measurements. The project uses the Iris dataset and K-Nearest Neighbors (KNN) algorithm for classification. It includes data preprocessing, model training, prediction, and evaluation using Python, Pandas, and Scikit-learn.

---

## 🚀 Features

* Predict Iris flower species
* Uses K-Nearest Neighbors (KNN)
* Simple command-line interface
* Beginner-friendly project
* High prediction accuracy
